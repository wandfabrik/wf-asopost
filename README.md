# あそポス

ボードゲームで遊んだ感想を、その場でかんたんに X（旧 Twitter）へ投稿してもらうための、QR 付き印刷カード生成ツールです。

ゲーム名・メンション先・ハッシュタグを入力すると、投稿の下書きを埋め込んだ QR コードと、印刷用カード（ポストカード／名刺サイズ・約 300dpi）を生成します。来場者が QR を読み取ると「『〇〇』で遊びました！」の下書きが立ち上がり、そのまま投稿できます。

ボードゲーム会・即売会・店舗などでの「遊んだ記録のシェア」を後押しします。

## 使い方

1. 公開ページを開く： https://wandfabrik.github.io/wf-asopost/
2. ゲーム名／メンション先（@アカウント・任意）／ハッシュタグ（任意）を入力
3. 印刷サイズを選ぶ（ポストカード 100×148mm ／ 名刺 91×55mm）
4. 「印刷用カードを書き出す（PNG）」でダウンロード → 印刷して会場に設置・配布

## 仕組み

- 入力 → X の Web Intent URL（`twitter.com/intent/tweet`）を生成し、QR コード化
- 文面は「『（ゲーム名）』で遊びました！」。メンションは本文末に付与
- カードは Canvas に約 300dpi で描画して PNG 書き出し
- 表示フォントは Zen Maru Gothic、QR 生成に qrcode-generator を使用
